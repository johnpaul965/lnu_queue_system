# LNU Queue System — Setup Instructions

## SQL
1. Open Supabase → SQL Editor → New Query
2. Paste the entire contents of complete_schema.sql
3. Click Run

## Flutter Files to Replace
1. Copy app_colors.dart → paste into lib/core/constants/app_colors.dart
2. Copy validators.dart → paste into lib/core/utils/validators.dart

## Then
Run: flutter pub get
Run: flutter run
